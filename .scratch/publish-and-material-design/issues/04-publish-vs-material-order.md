# Publish first, Material first, or independent?

Type: grilling
Status: resolved
Blocked by: 01, 03

## Question

In what order should publishing and the Material Design move happen, and what high-level Material approach do we take? Decide with Eric.

## Answer

**Order: publish first.** Eric wants to use it on his phone at practice that evening, and does not mind restyling a live site later. Publish the current look on GitHub Pages (see Host options), then restyle as a separate effort.

**Approach: not decided here.** Eric's main reason for a design system is mobile (parents are on phones), with a liking for comprehensive docs and open source. He is open to a system other than Material, possibly React-based since he uses it at work. That reopens the "no framework, no build step" constraint in the power-ranking-app spec, so it moves to two new tickets: Design system options (research) and Design system and React decision (grilling).

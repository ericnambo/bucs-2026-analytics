# 02: Results view

**What to build:** The app opens from a folder (no server) and shows every past Peewee game as a table row. The user can filter by week and by team, follow each row's link to its source scoreboard image, and see forfeits and extraction-problem flags marked in text. This is the app shell the other views build on, and where the user verifies the extraction.

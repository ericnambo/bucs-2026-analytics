# Ideas

Parking lot for feature ideas. When one is ready, turn it into a numbered ticket in `issues/`.

## Candidates

- **Hosting**: publish the app (for example GitHub Pages). Currently out of scope in `spec.md`.
- **Other divisions**: Freshman, Sophomore, Junior, Senior. Division is already a data field.
- **Weekly data updates**: easier way to add each new week's scores.
- **Favorite team**: let the user pick a favorite team so the Matchup default and row highlighting follow that team across the whole app, instead of being fixed to the Bucs.
- **Design system**: pick a design system so the app looks better on mobile. Must keep the no-framework, no-build-step constraint in `spec.md` (or revisit it).
- **Coach-only features**: password-protect advanced analytics and prediction features so only authorized users in the Bucs organization can see them. Keep the first version simple. Note: `spec.md` lists accounts and a backend as out of scope, and a client-side password is only a soft gate, not real security.
